Thank you for purchasing the Sign Decals Volume I Pack. A lot of effort has been put into creating this asset pack and our team is more than willing to help you.

In order to correctly set this asset pack and enjoy it certain Unity 3D settings must be set.

- Edit>Other Settings>Player : Rendering > Color Space > Linear

One scene is included in the pack for showoff purposes. The Substance Painter tools with the 74 decals are included in the folder Substance Painter Tools. 

Installation 

Just drag and drop the .sppr files into the Substance Painter Shelf and then import to either current session or the shelf 'shelf' for use in all your projects.
All decals have 4096x4096 resolution for best quality. We recommend working in 2K for faster response.
